# Session transcripts

Never suggest, delete, move, compress or truncate agent session history,
directly or through a parent directory, and never shorten a host's retention
setting. This covers `~/.claude/projects`, `~/.claude/history.jsonl`,
`~/.codex/sessions`, `~/.codex/archived_sessions`, `~/.codex/history.jsonl`,
`~/.local/share/muse/sessions`, `~/.local/share/muse/session-index.db*`,
`~/.local/share/muse/tui-history.jsonl` and any other agent host's session
history, compressed or not. It is the only
record of past work and cannot be rebuilt. A storage target that cannot be met
without it ends as a reported gap.
