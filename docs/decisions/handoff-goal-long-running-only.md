# Decision: handoff-goal is for long-running work only

## Context

[The earlier scope decision](handoff-goal-description-scope.md) closed one gap
between the trigger and the fit check: it removed "a brand-new idea" so
open-ended research would stop reading as a valid goal source. A second gap
survived it.

The description asked only that a goal be **defined**: stateable up front and
verifiable by checks that can fail. Nothing in it asked how *long* pursuit
would take. A small, well-specified task passes that test perfectly, so the
trigger fired on work the session it was written in could simply have
finished. The body's fit check names the real criterion ("progress needs
repeated attempts, waiting, or recovery"), but the fit check runs after the
skill is already loaded, and by then a contract directory feels like the
answer.

Definedness and duration are independent, and the trigger was only testing the
first one.

## Change

The description leads with the constraint: **only for long-running work that
must outlive this session**, a goal a fresh session pursues over many turns.
The exclusions follow: work this session can finish, and open-ended research.
The protocol text the description used to carry ("never pursues the goal
itself", the stateable-and-verifiable fit criteria) drops out; both already
live in the body.

The body states the same constraint at the top of *When to use*, and the fit
check's list of disqualifiers gains "work that fits in one session" alongside
one-shot work and taste-driven choices.

## Consequences

- Length is not a proxy for importance. A well-defined goal that fits in the
  session at hand is now explicitly the wrong fit, and the lighter tool (a
  plain task) is the recommendation.
- The two places that offer this route follow: `brainstorming`'s route gate
  marks it long-running-work-only, and `using-workbench`'s ownership row reads
  "a long-running autonomous goal, outliving this session".
- Critique mode is unaffected: auditing an existing contract is still a
  direct-invoke path with no duration test.
